
# PyTorch Text Classification

My text classification project using PyTorch.

## Overview
This project explores text classification using PyTorch and the AG News dataset.

## Objectives
- Preprocess and tokenize text data.
- Build a vocabulary.
- Train a neural network for text classification.
- Evaluate model performance on validation data.

## Technologies
- Python
- PyTorch
- TorchText
- NumPy
- Matplotlib

## Dataset
AG News is a news-topic classification dataset with four categories.

## How to run
1. Open the notebook in Google Colab.
2. Install the required package versions.
3. Run the cells in order.

## What I learned
- Text preprocessing and tokenization.
- Embeddings and neural network training.
- Loss functions, optimization, and model evaluation.
